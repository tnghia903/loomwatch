    02 A real run, every morning

    A daily tech digest, checked against sources you trust.

    Every morning at 9:00, one agent gathers the last day's stories from the sources you listed. A second reads each story at its sources and keeps only what they stand behind, and a third writes it up. Nothing waits for you: the digest is done before you open it.

    Every day 09:00→Gatherer Codex→Reader Claude→Writer Claudeall three read sources.md

    Your sources, in a file
    The trusted list and the rule for keeping a story sit in the team's Brief, a Markdown file every agent reads. Edit it, and tomorrow's run follows it.
    Two sources, or it's out
    A story stays only if its own primary source says it, or two independent newsrooms report it. Reader opens every source it can and checks the rest through web search, never on the headline alone.
    It runs on its own
    No stop for you. In a scheduled run anything not switched on is declined, so only web search is on, and only for Gatherer and Reader.
    Two companies at one desk
    Codex gathers, Claude reads and writes, so one model never decides alone what's true.
    Teach it once
    Write "fewer funding stories" in the Notebook and keep it. Every later digest reads it.
    The request it runs

    Today's tech news digest for {{weekday}} {{date}}: what happened in the last 24 hours, confirmed by the trusted sources in the Brief.

    Seven of the trusted newsrooms won't let Claude open their pages. The Brief names them, so Reader checks their stories through web search instead. The receipt shows every step finished, with nothing flagged.
