One run, start to finish

This page is a LoomWatch run, and you're the operator. Choose your apps, build a team, ask it for something, and decide what happens when it stops for you.

Everything below runs in your browser. Nothing calls a model, and nothing you type leaves this page.

01 Threads

Start with the threads you already have.

LoomWatch finds the AI apps on your computer and puts each one on the loom as a thread. Tick the ones you use, and the rest of this page weaves with them.

No API key
Each agent runs on an app you've already signed in to.
Your plans, as they are
Runs count against those apps' own plans, as if you'd used them yourself.
Mix them on one team
Each agent has its own app and model. Through OpenCode, open models such as DeepSeek, Kimi, GLM, Qwen or Mistral too.

    02 Build

    Hire by job. Read the team back as one sentence.

      03 Give
      
    Hand each agent what it needs. Share it with a drag.
    
      
    Folders, files, skills and tools sit on the canvas as cards. Drag one onto an agent, and it's handed to that agent at the start of every run. Drag the same card onto a second agent and they share it: one card, two threads.
    
      
    
        
    Your project stays yours
    An agent works in the folder you choose, and changes files there only if you allow it. What you hand it is read only, and nothing is written into your project.
    
        
    Exactly what arrives
    A folder arrives as its listing and README, a file as its text, PDFs included, and a skill as its instructions. The record shows which ones were opened.
    
        
    Three switches each
    Search the web, edit files, run commands. Anything else an agent asks for waits for your answer, mid-run.

      05 Watch
      
    Watch every thread as it's woven.

    Evidence, not guesses
    A skill shows as loaded only when it was actually sent, and a file as opened only when the agent's own stream read it.

      06 Review
      
        Nothing moves on until you decide.
        
      
        Put yourself on the team as a step. When the run reaches you, it stops and shows what was handed over. Approve it, or say what to change and send it back, so a weak first step never quietly shapes everything after it.
        
      
        
        
        Easy answers stay easy
        Approve without a comment, or send it back with one line.
        
        
        Agents can ask you, too
        Mid-run, an agent can stop and put a question to you.
        
        
        It waits, even on a schedule
        A review step in a 10:00 run still waits for you.
        
        
        Never decided for you
        Ask LoomWatch can propose teams and start runs, but it can never answer a review step.

      07 Result
      
        The answer comes with its receipt.
        
      
        The team's answer opens in a reader, beside a run receipt: what you asked, who did what, how long it took, and anything worth a second look. Not quite right? Follow up, or redo from the step that went wrong.
        
      
        
        
        Follow up
        Ask for another pass on the result, and the team picks up from there.
        
        
        Redo from a step
        Run again from the step that went wrong. The steps before it keep their work.
        
        
        Files, not paths
        A file the team made opens as a card: open it, show it in its folder, or copy its path.

        09 Why a loom
        
        Most team features come from one AI company. A loom takes anyone's thread.
        
        
        AI apps leapfrog each other every few months. LoomWatch doesn't belong to any of them, so each job gets the app that does it best. When a better one ships, you change one thread, not your whole setup.
        
        
        
          
          
        
        
      
        
      
    
        

    
          
      
        1. i
          Any app, one team
          Claude, Codex, Gemini, OpenCode, Hermes and OpenClaw, side by side, each on the job it does best.
          2. 
      
        2. ii
          On your computer
          LoomWatch serves on 127.0.0.1 and keeps run history in a database on your computer. Your teams are plain files, and your folders stay where they are.
          3. 
      
        3. iii
          On the plans you have
          No API key and nothing new to sign up for. Runs use the sign-ins you already have.
          4. 
      
        4. iv
          With you in it
          You're a step on the team, not a spectator. It stops wherever you put yourself.
          5. 
      
        5. v
          Proof, not a guess
          Handovers are recorded as calls, not read out of chat, so the receipt only says what happened.
          6. 
      
        6. vi
          Context that outlives a switch
          The Brief, the Notebook, every folder and file you handed over, and every run stay with your team, whichever app you swap in.
          7. 
    
        
    
        To be exact about privacy: LoomWatch itself sends nothing anywhere unless you turn on Send to Notion, which posts the team's answer to your Notion. Each agent's own app still sends prompts and files to its model provider, as it does when you use it directly.
        
  
        

        



        
  
        
    
        
      
        
        10 Start
        
        One command, and your first team is already waiting.
        
        
        The first start takes a few minutes. Then LoomWatch opens in your browser with an offline demo team you can run before you connect any AI app.
        
        
        
          
        Docker
        Docker Desktop, OrbStack or Docker Engine, for the database that keeps your run history.
        
          
        Node.js 22.12+ and Rust
        To build it. The exact Rust version downloads on its own.
        
          
        Access to the repository
        It's private for now, so clone it with a GitHub account that has access.
        
          
        An AI app, signed in
        For real runs. The demo team needs none.
        
        
        
      
        
      
        
        
        Terminal
        

        $ git clone git@github.com:tnghia903/loomwatch.git
$ cd loomwatch
$ ./loomwatch
==> LoomWatch is starting at http://127.0.0.1:3000
Keep this window open while you use LoomWatch. Press Ctrl-C to stop it.
        
        
        ./loomwatch lists anything missing and how to install it. ./loomwatch stop stops it, ./loomwatch update gets the latest version, and your teams and history are kept either way.
